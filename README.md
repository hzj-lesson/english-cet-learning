# 英语四六级学习平台

专为 **2026 年 12 月四六级考试**打造的单文件纯前端学习应用。无需安装、无需后端、无需注册 —— 浏览器打开即用，数据全部保存在本地浏览器中。

> 🎯 笔试 2026-12-19 · 口试 2026-11-21

## ✨ 六大功能模块

| 模块 | 功能 |
|------|------|
| 📋 仪表盘 | 考试倒计时、总进度环、26 周打卡热力图、今日待办 |
| 🗂️ 路线任务 | S0~S3 四阶段 31 个备考任务（CET-4 / CET-6 分级） |
| 🃏 单词本 | 高频核心词闪卡记忆，四态记忆循环 + 今日复习队列 |
| 🍅 番茄钟 | 专注 25' / 短休 5' / 长休 15'，时间戳校准防丢秒 |
| 📝 笔记日志 | 学习笔记、每日日志、错题本 |
| 🔗 资源 | 刷题、听力、写作、真题等优质资源导航 |

## 🚀 使用方式

1. 在线使用：访问 GitHub Pages 地址即可
2. 本地使用：下载 `英语四六级学习平台.html`，双击用浏览器打开

## 💾 数据安全

- 所有数据仅保存在**你自己的浏览器**（localStorage），不上传任何服务器
- 支持 **导出 / 导入 JSON 备份**，可跨设备迁移
- 支持快照恢复，防止误操作丢失数据
